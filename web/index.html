Per-instructie TASM → WebAssembly

ASM2Web compileert historische 16-bit x86 assembly (TASM-dialect) deterministisch naar WebAssembly. Frame N is een pure functie van (program-bytes, frame-index, input). Geen emulator. Geen rewrite. Geen Math.random(). Geen wallclock-jitter.

v0.5.0-Stibitz · fase 1-7 (+ x86 segment:offset memory-tracker — ES:[DI]/DS:[SI] pixel-exact)

▸ TECHNO — browser-runtime + audio (Future Crew 1993)

KOEA + KOEB + POLYCLIP (1288 ops, 27 procs) gelinkt in 1 WASM-module (59699 B) met _circle + _circle2 data ge-embed. KOE.C driver in JavaScript + chiptune3 (libopenmpt) audio met MUSIC0.S3M. Build-determinisme bewezen.

▸ STARFIELD — tweede scene (DDSTARS)

KOE + STARS + POLYEGA (1325 regels, 23 procs, 969 IR-ops) door dezelfde pijplijn als TECHNO. Bewijst generiekheid van de stack: zelfde tokenizer/parser/IR/codegen pakt nieuwe scene zonder pijplijn-wijzigingen.

▸ Mini demo — hello-pixel · seg-test

Eenvoudige TASM-bron (~30 regels), bewijst de pijplijn end-to-end. De seg-test-demo bewijst de x86 segment:offset-tracker: mov ax,0a000h / mov es,ax wordt herkend als segment-base const-load, en es:[di]/ds:[si] resolveren byte-exact naar linear 0xA0000+offset.

Drie bewijslast-niveaus

Build-determinisme
Zelfde source → byte-identieke .wasm. Bewijs: sha256(build1) == sha256(build2).
Runtime-determinisme
Zelfde program + input-trace + frame-N → byte-identieke pixel-bytes. Bewijs: gouden-frame snapshots.
Audio-determinisme
Zelfde program + frame-N → byte-identieke sample-buffer. Bewijs: WAV-checksum per N seconden.
