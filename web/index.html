Per-instructie TASM → WebAssembly

ASM2Web compileert historische 16-bit x86 assembly (TASM-dialect) deterministisch naar WebAssembly. Frame N is een pure functie van (program-bytes, frame-index, input). Geen emulator. Geen rewrite. Geen Math.random(). Geen wallclock-jitter.

Drie bewijslast-niveaus

Build-determinisme
Zelfde source → byte-identieke .wasm. Bewijs: sha256(build1) == sha256(build2).
Runtime-determinisme
Zelfde program + input-trace + frame-N → byte-identieke pixel-bytes. Bewijs: gouden-frame snapshots.
Audio-determinisme
Zelfde program + frame-N → byte-identieke sample-buffer. Bewijs: WAV-checksum per N seconden.
