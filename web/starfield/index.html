Originele DDSTARS-kenmerken

  • Mode-X (VGA 320×400) i.p.v. mode-13h, met page-flipping
  • EMM (INT 67h) gebruikt voor 4-page tile-buffer — wij vlakken dit naar linear memory
  • VGA Sequencer plane-mask (port 3C4h/3C5h) voor planar writes
  • 1024-entry sine-table (sin1024.inc) voor star-rotation
  • Externs: _textpic (uit _TEXTPIC.OBK, planar bitmap) + _dis_partstart (DIS-engine, in onze versie no-op)

Net als TECHNO: visueel-approximatie omdat onze runtime flat-memory + 16-bit reg-only is. WASM-output is byte-reproduceerbaar tussen runs.
