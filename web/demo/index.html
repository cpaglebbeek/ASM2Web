Wat bewijst dit?

      
    
        
  • P-DET-02 (build-determinisme): de WASM-SHA hierboven matcht tussen runs op verschillende machines. Geen timestamps, geen optimizer-randomness.
    • 
        
  • P-DET-01 (runtime-determinisme): zelfde WASM + zelfde initial state → zelfde framebuffer na main(). Geen RNG, geen wallclock in render-pad.
    • 
        
  • Pijplijn-correctheid: de zichtbare pixels op (10,10), (20,20), (50…59, 100) komen exact uit de mov [absolute_offset], al-instructies in de source.
    • 
        
  • Niet bewezen: control-flow (jumps, loops), call/ret, push/pop, audio, vsync. Komt fase 4.2+.
